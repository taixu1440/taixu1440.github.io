什么是redis

Redis 是一个存数据在内存里的数据库，读写速度极快。你可以往里面存键值对（比如 SET name "张三"），也可以让它把数据存到硬盘上的文件里。

其属于NoSQL 数据库（非关系型数据库），具体是键值存储类型。

网络协议访问

Redis 使用文本协议，可以直接用 telnet 或 nc

正常不支持http访问，但可以利用CRLF注入

CRLF注入

Redis 只认 TCP 文本命令，原本和http不兼容，但通过 CRLF 注入，让 Redis 把 HTTP 请求误读成多条 Redis 命令，即造成协议混淆。
