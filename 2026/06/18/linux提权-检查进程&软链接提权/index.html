检查进程

这里就蛮明显的start.sh在运行

这里很明显就存在本章要讲的软链接提权

软链接提权

这里有个关键命令

我们先来了解一下cp的参数

第一个参数为源文件，第二个参数为路径

这里如果源文件是快捷方式，参数-P会让其只复制这个快捷方式，如果是-L，则会复制这个快捷方式指向的文件

而另一个需要注意的点，就是替换*的当前目录(/var/www/html/primary)文件名是直接被拼接到命令中的

现在我们看/var/www/html/primary是空的，如果我们创建一个文件名叫-L来替换*，命令就会变成

后一个参数覆盖前一个参数，整条命令参数变成-L，这时候就能够复制快捷方式指向的真实内容到目录/var/www/html/marstream/

若我们同时创建两个文件 一个叫-L 一个叫任意名字比如file，这样file为快捷方式，指向/flag

这样*就换成了-L file

成功将/flag复制进了/var/www/html/marstream/ 文件名为file

又知道/var/www/html/marstream/在html目录下可访问，我们访问也好或者直接cat，反正都是有权限的

这就是间接利用cp，直接利用软链接将不可读目录的文件复制到可读目录之中

还有需要注意的一点是这里的进程是root开的，意味着所有命令都有权限操作高权限文件

这里没办法使用cp提权，但是截断符进行RCE可以试一试，最后没复现出来
