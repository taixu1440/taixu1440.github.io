概念

堆叠注入（Stacked Queries） 是指在一次SQL查询中，通过分隔符（如分号 ;）执行多条SQL语句的注入攻击技术。

堆叠注入触发的条件很苛刻，因为堆叠注入原理就是通过结束符同时执行多条sq语句，这就需要服务器在访

问数据端时使用的是可同时执行多条sql语句的方法，例如php中的mysqli_multi_query函数。

但与之相对应的mysqli_query函数一次只能执行一条sql语句，所以要想目标存在堆叠注入，在目标主机没有对堆叠注入进行黑名单过滤的情况下必须存在类似于mysqli_multi_queryo这样的函数

先来了解这三个php的sql语句

mysqli_multi_query($db, $sql)

这个已经很熟知了，前一个是数据库名，后一个是sql语句，能够包含多条，是堆叠注入的核心

mysqli_store_result($db)

从多查询中获取当前语句的结果集，返回这个结果集供其他函数处理。

mysqli_fetch_row($result);

参数为结果集，从结果集中取出一行数据，作为索引数组（数字下标）返回。

从结果的第1行，不是整个表的第1行开始每次调用返回当前指针所在的行，然后自动向下移动一行。

-- 标准语法
INSERT INTO 表名 (列1, 列2, 列3) VALUES (值1, 值2, 值3);

-- 插入所有列（省略列名）
INSERT INTO 表名 VALUES (值1, 值2, 值3);

-- 插入多条数据
INSERT INTO 表名 (列1, 列2) VALUES (值1, 值2), (值3, 值4), (值5, 值6);
