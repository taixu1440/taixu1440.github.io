js安全·一--nodejs原型链污染

发表于2026-04-22|更新于2026-07-16|-training
|浏览量:

js原型链污染是一种针对 JavaScript 对象原型系统的攻击：攻击者通过可控输入修改对象的原型链（通常是 Object.prototype 或任意共享原型），从而在所有继承该原型的对象上注入新属性或覆盖已有属性，进而改变程序行为或触发安全缺陷。

本质：共享引用 → 全局生效。

前置知识

在学习原型链污染之前，需要先理解几个JavaScript的核心概念。

原型链的核心概念

对象与原型

每个对象都有一个原型（proto），对象会从原型上继承属性和方法。

原型链

原型链就像一条”继承链”，一层一层往上找属性。

这里和python相似，万物都是对象

在调用对象的成员时，程序会先从对象自身查找，若无，则至对象的原型链查找

当数组/对象等被创建时，其成员__proto__会指向这个变量类型的原型，即Array/Object.prototype，这个原型是相同的数据类共用的，因此可以通过一个变量访问__proto__来污染所有变量的__proto__

这就是原型链污染的基本原理

函数与对象

在js中，函数的调用方式决定了它的身份(是面向过程还是面向对象)

一个函数既可以当做面向过程的普通函数，也可以当做面向对象的函数调用

需要注意的是，面向对象的构造函数通常首字母大写（约定），且js的对象一般不存在析构函数，析构函数需要以不同的形式进行显式调用

new函数与prototype

每个函数在定义时，都会自动创建一个全新的 prototype 对象：

这样的对象因函数名而异，而非统一的function.prototype

而new 命令强制规定，用new创建的对象，它的__proto __要指向<函数名>.prototype，在如下程序是 User.prototype，而不是通用的 Object.prototype。

user1的__proto__指向的就是User.prototype了，而非object.prototype，原生的内容只有一个constructor成员，但可以通过访问进行手动添加

js类的方法

js类的方法定义有很多种方式

变量定义时定义

直接在变量内部定义是最直接的办法

定义在构造函数中

构造函数中可以定义成员，类中方法也属于成员

挂载在 prototype 上

这就是污染的原点了，因为对象的prototype都是共用的，为object.prototype，除非这个函数使用构造函数定义

js对象的constructor与prototype

在js中，每一个对象都有constructor，如果对象是通过变量定义创建的，其constructor为object，如果对象是通过函数创建的，其constructor为这个函数

函数也有constructor，它的constructor为function

访问一个对象的prototype，你既可以通过objectname->__proto__，也可以通过objectname->constructor->prototype，这两个的结果一般是相同的，这个结论自证不难

需要注意的是，函数->constructor->constructor为object，通过函数创建的对象，其objectname->constructor->constructor为function，而function->constructor恒为function

即

来自定义的对象:

objectname->constructor=object

objectname->__proto__=object->prototype

objectname->constructor->prototype=object->prototype

来自构造函数functionname的对象:

objectname->constructor=functionname

objectname->constructor->constructor=function

objectname->constructor->constructor->...->constructor=function

objectname->__proto__=function->prototype

objectname->constructor->prototype=function->prototype

来自定义的函数functionname:

functionname->constructor=function

functionname->prototype=functionname.prototype(函数自己就有prototype)

functionname->__proto__=functionname->constructor->prototype=function->prototype

JSON.parse函数

JSON.parse 是 JavaScript 提供的一个方法，用于将 JSON 字符串转换为 JavaScript 对象。

需要注意的是，不能通过json来访问__proto__成员，它会被直接解析为成员变量

原型链污染漏洞利用

总的说，原型链污染利用了以下两点：

  1. 在调用对象的成员时，程序会先从对象自身查找，若无，则至对象的原型链查找

  2. 一个对象的原型链可以使用特殊的手法通过另一个对象进行访问，这样就能直接修改这个对象原型链的成员

所以，当程序中使用了可控的、递归的对象合并（Merge）、复制（Clone）或设置属性（Set Property）的操作，使得攻击者能够修改或注入属性到全局的 Object.prototype 上时，原型链污染 就会发生

环境变量NODE_OPTIONS

因为 NODE_OPTIONS 是 Node.js 官方提供的、可以影响进程行为的入口。一旦控制了它，就能：

  1. 在进程启动时执行任意代码（通过 -r 或 --require）

  2. 修改内存/GC 行为（通过 --max-old-space-size 等）

  3. 开启调试器（通过 --inspect）

而当输入-r时，要求文件是json形式，如果格式不符，就会通过报错显示文件内容，从而做到任意文件读取。

一般情况下，process.env->NODE_OPTIONS默认不存在，我们可以做的是先修改object->prototype->NODE_OPTIONS，当访问process.env->NODE_OPTIONS出现不存在时，按照原型链规则，会访问process->env->__proto__->NODE_OPTIONS，即object->prototype->NODE_OPTIONS

所以本题答案在理解了原理后，就很容易构造了
