概述

在 Linux 中，sudo 允许普通用户以其他用户身份执行命令，最常见的是以 root 权限执行。所谓 sudo 提权，本质上是利用系统管理员在 /etc/sudoers 或 /etc/sudoers.d/ 中配置不当，让低权限用户通过某些被允许的命令获得更高权限。
